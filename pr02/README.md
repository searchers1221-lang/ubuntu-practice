# Практическая работа №2. Bash и системные вызовы (вариант A)

## Цель работы
Освоить написание Bash-скриптов и изучить системные вызовы Linux с помощью strace.

## Запуск
    chmod +x stats.sh
    ./stats.sh

## Результат работы stats.sh
Скрипт перебирает все файлы data/*.log, считает строки с ERROR через grep -c, суммирует и находит файл с наибольшим числом ошибок. Всего ERROR: 473, больше всего в data/25.log (18).
Полный вывод в файле stats_output.txt.

## Системные вызовы (strace -c)

Три самых частых системных вызова (и у ls, и у cat):
- mmap (27 раз): отображает файлы и библиотеки в память процесса, выделяет память.
- read (18 раз): читает данные из открытого файла.
- openat (12 раз): открывает файл или библиотеку и возвращает его дескриптор.

Также часто встречается close (закрывает дескриптор): 11 раз у ls и 13 раз у cat.
Всего вызовов: ls 144, cat 142.

Статистика для ls: strace_ls.txt. Статистика для cat: strace_cat.txt.

## Зачем cat открывает библиотеки до файла

Команда cat собрана динамически: функции чтения и записи она берёт из общих библиотек, главная из них libc.so.6. Перед запуском программы загрузчик находит и подключает эти библиотеки (в strace_openat.txt видно ld.so.cache, libselinux, libgcc_s, libm, libc, libpcre2). Только после этого cat может выполнить свою работу и открыть data/01.log, поэтому этот вызов идёт последним.

## Выводы
Даже простые программы (ls, cat) делают больше сотни системных вызовов: пользовательская программа не работает с диском напрямую, а просит ядро через системные вызовы. Значительная часть вызовов уходит на загрузку библиотек и подготовку программы к работе.
